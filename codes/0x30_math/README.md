# 0x30 Math

数学专题索引。内容覆盖数论、组合、线代、博弈、概率和多项式。题目代码按来源归档，模型和模板按复用稳定程度放入 model/template。

## 知识点索引

| 方向 | 知识点 | 复习重点 |
| --- | --- | --- |
| 基础数论 | 整除、素数、筛法、分解质因数 | 约数结构、质因数指数、复杂度。 |
| GCD 与同余 | 欧几里得、扩展欧几里得、CRT | 线性同余、逆元、模数不互质。 |
| 快速幂与逆元 | 二进制幂、费马小定理、欧拉定理 | 模乘溢出、负数取模、组合数预处理。 |
| 组合数学 | 排列组合、容斥、Catalan、Stirling | 计数对象、重复/有序/无序条件。 |
| 线性代数 | 矩阵、线性基、高斯消元 | 异或空间、秩、可表示性。 |
| 多项式 | NTT、卷积、生成函数 | 模数选择、长度补齐、形式幂级数。 |
| 概率与期望 | 条件概率、期望线性性、Markov 过程 | 状态定义，转移概率，总概率公式。 |
| 博弈论 | SG 函数、Nim、必胜必败态 | 状态图、mex、异或和。 |
| 随机化 | 随机哈希、随机采样、Monte Carlo | 失败概率、种子、对拍验证。 |
