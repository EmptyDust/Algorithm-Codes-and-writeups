# 0x30 Math

这里作为数学专题索引和历史题目入口。内容覆盖数论、组合、线代、高精度、博弈和随机化等方向。新题代码优先按来源放入 [`../-0x30_competition`](../-0x30_competition/)。

## 子目录

| 目录 | 内容 |
| --- | --- |
| [`0X33_random`](./0X33_random/) | 随机化算法与概率化技巧。 |
| [`0x39_interactive`](./0x39_interactive/) | 交互题相关数学策略。 |

## 使用约定

数学题建议在索引、题解或同名笔记里保留核心转化。若题目主要是组合计数，也可以按需要同步到 [`../0x40_combinatorics`](../0x40_combinatorics/) 的复习索引。
