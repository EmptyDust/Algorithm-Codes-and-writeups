# 0x90 Construct

构造题专题索引。构造题通常不依赖固定模板，重点是发现结构、证明合法性，并处理无解条件。

## 知识点索引

| 方向 | 知识点 | 复习重点 |
| --- | --- | --- |
| 不变量 | 奇偶性、和、异或、连通性、度数 | 找到操作无法改变的量。 |
| 逆向构造 | 从目标倒推、撤销操作、归纳构造 | 保证每一步都能回退到更小规模。 |
| 贪心构造 | 排序、局部填充、最小可行选择 | 证明局部选择不阻塞后续。 |
| 分治构造 | 递归拆分、块构造、拼接 | 子结构之间的边界兼容。 |
| 图构造 | 度数序列、连通图、树、二分图 | 图论必要条件和构造算法。 |
| 序列构造 | 排列、括号序列、矩阵、网格 | 位置约束、行列约束、字典序。 |
| 交互构造 | 询问策略、信息增益、容错 | 询问次数和反馈不确定性。 |
| 反例构造 | Hack、极端数据、边界数据 | 找最小坏例和结构性坏例。 |
