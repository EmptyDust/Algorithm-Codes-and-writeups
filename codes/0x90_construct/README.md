# 0x90 Construct

这里作为构造题专题索引和历史题目入口。重点是发现结构、给出可证明的构造方式，并处理无解条件。新题代码优先按来源放入 [`../-0x30_competition`](../-0x30_competition/)。

## 子目录

| 目录 | 内容 |
| --- | --- |
| [`0x91_array`](./0x91_array/) | 数组、排列、序列构造。 |

## 使用约定

构造题建议在题解或索引中写清楚不变量、合法性证明和无解判定。若构造依赖某个强专题，可以在对应专题中交叉链接同一份来源代码。
