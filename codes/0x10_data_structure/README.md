# 0x10 Data Structure

数据结构专题索引。普通题目代码按来源归档；这里负责组织复习路径，并链接到稳定模板或模型实现。

## 知识点索引

| 方向 | 知识点 | 复习重点 |
| --- | --- | --- |
| 线性结构 | 数组、链表、栈、队列、双端队列 | 维护相邻关系、单调性和操作顺序。 |
| 单调结构 | 单调栈、单调队列 | 最近更大/更小元素，滑动窗口最值。 |
| 哈希结构 | `map`、`unordered_map`、计数表 | 哈希碰撞、键设计、离散值统计。 |
| 堆与优先队列 | 二叉堆、懒删除、多路合并 | 动态维护极值，处理过期元素。 |
| 并查集 | 路径压缩、按秩合并、带权并查集 | 连通性、等价关系、约束维护。 |
| 树状数组 | 单点修改、区间查询、差分、二分 | 前缀维护、逆序对、离线计数。 |
| 线段树 | 单点/区间修改、懒标记、动态开点 | 信息合并、标记下传、边界拆分。 |
| ST 表 | 静态 RMQ、幂次拆分 | 可重复贡献查询，预处理与查询边界。 |
| 平衡树 | PBDS、Treap、排名、前驱后继 | 动态有序集合，顺序统计。 |
| 位集 | `bitset`、位运算压缩 | 状态压缩、批量转移、空间换时间。 |
| 根号结构 | 分块、莫队、块状链表 | 修改查询折中，按块维护摘要。 |
