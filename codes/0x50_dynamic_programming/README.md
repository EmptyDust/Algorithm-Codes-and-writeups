# 0x50 Dynamic Programming

这里作为动态规划专题索引和历史题目入口。重点是状态设计、转移优化、边界初始化，以及把题意拆成可维护的子问题。新题代码优先按来源放入 [`../-0x30_competition`](../-0x30_competition/)。

| [`0x53_subquence`](./0x53_subquence/) | 子序列、LIS/LCS 类问题。 |

## 使用约定

如果题目核心是树、图或数据结构上的 DP，也可以在对应专题中保留链接。题目代码本体仍以来源目录为主。
