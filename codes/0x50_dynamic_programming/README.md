# 0x50 Dynamic Programming

动态规划专题索引。DP 是状态设计和转移组织的方法，不是单一算法；题目代码按来源归档，这里保留复习路径和少量未确认来源文件。

## 知识点索引

| 方向 | 知识点 | 复习重点 |
| --- | --- | --- |
| DP 基础 | 状态、转移、阶段、初值、答案位置 | 最优子结构、无后效性、子问题重叠。 |
| 线性 DP | LIS/LCS、最大子段和、序列划分 | 位置含义，前缀转移，滚动数组。 |
| 背包 DP | 01/完全/多重/分组背包 | 枚举顺序，容量维度，方案计数。 |
| 区间 DP | 合并石子、括号匹配、回文区间 | 区间长度枚举，断点枚举。 |
| 树形 DP | 子树合并、换根 DP、树上背包 | 父子状态，根的选择，合并复杂度。 |
| DAG DP | 拓扑序 DP、最长路/计数 | 状态图无环，转移方向。 |
| 状压 DP | 子集枚举、TSP、轮廓线 | 子集转移，补集枚举，复杂度压缩。 |
| 数位 DP | 前缀限制、前导零、记忆化搜索 | `limit`、`lead`、状态缓存条件。 |
| 概率 DP | 期望、概率转移、吸收状态 | 方程含义，倒推/正推方向。 |
| DP 优化 | 单调队列、斜率优化、分治优化、四边形不等式 | 优化条件证明，决策单调性。 |
