# 0x20 Computational Geometry

计算几何专题索引。题目代码按来源归档；这里记录几何建模和复习顺序。

## 知识点索引

| 方向 | 知识点 | 复习重点 |
| --- | --- | --- |
| 基础对象 | 点、向量、直线、线段、圆 | 坐标类型、精度误差、比较函数。 |
| 向量运算 | 点积、叉积、方向判断、投影 | 角度、垂直、平行、面积和左右侧。 |
| 位置关系 | 点在线段上、线段相交、点到线距离 | 边界包含、共线和端点处理。 |
| 多边形 | 面积、点在多边形内、凸多边形 | 有向面积、射线法、二分判点。 |
| 凸包 | Andrew、Graham、动态凸包 | 排序、去重点、共线点保留策略。 |
| 旋转卡壳 | 直径、最远点对、最小矩形 | 单调指针，凸包上的极值维护。 |
| 扫描线 | 矩形面积并、线段事件、离散化 | 事件排序，线段树维护覆盖长度。 |
| 半平面与圆 | 半平面交、圆交、切线 | 精度控制和特殊情况分支。 |
