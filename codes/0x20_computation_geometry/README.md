# 0x20 Computation Geometry

这里保存计算几何题目。内容以几何对象建模、坐标运算、扫描线和凸包相关技巧为主。

## 子目录

| 目录 | 内容 |
| --- | --- |
| [`0x21_scan_line`](./0x21_scan_line/) | 扫描线与平面事件处理。 |
| [`0x22_math`](./0x22_math/) | 几何中的数学计算与公式。 |
| [`0x23_rotating_calipers`](./0x23_rotating_calipers/) | 旋转卡壳与凸包相关问题。 |

## 使用约定

几何题优先保留关键精度处理、坐标类型和边界情况说明。若只是普通数学推导而没有几何对象，归入 [`../0x30_math`](../0x30_math/)。
