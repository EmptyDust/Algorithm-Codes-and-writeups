# -0x40 Template

这里保存更稳定、可直接复制到比赛代码中的模板。和 [`../-0x10_model`](../-0x10_model/) 相比，这一层更强调“比赛现场可用”和“接口固定”。它不保存普通题目提交代码。

## 子目录

| 目录 | 内容 |
| --- | --- |
| [`-0x41_data_structure`](./-0x41_data_structure/) | 数据结构模板。 |
| [`-0x42_misc`](./-0x42_misc/) | 杂项模板与常用片段。 |
| [`-0x43_math`](./-0x43_math/) | 数学模板。 |

## 使用约定

模板文件应尽量保持独立、少依赖、接口清晰。正在探索或仍不稳定的写法先放在 [`../-0x10_model`](../-0x10_model/)；普通题目代码放在 [`../-0x30_competition`](../-0x30_competition/)。
