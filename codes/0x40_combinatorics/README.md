# 0x40 Combinatorics

组合数学专题索引。普通组合计数也可归入 [`../0x30_math`](../0x30_math/)；这里单独保留更偏“计数结构”的复习路径。

## 知识点索引

| 方向 | 知识点 | 复习重点 |
| --- | --- | --- |
| 基础计数 | 加法原理、乘法原理、排列组合 | 是否有序、是否可重复、对象是否可区分。 |
| 二项式 | 组合数、Pascal、Lucas、组合恒等式 | 模数、预处理范围、恒等变形。 |
| 容斥 | 普通容斥、二项式反演、莫比乌斯反演 | 事件集合、符号、重复计数来源。 |
| Catalan | 括号序列、栈序列、路径计数 | 非负前缀约束和递推形式。 |
| 置换 | 循环分解、错排、Stirling 数 | 排列结构和组合意义。 |
| 群作用 | Burnside、Polya | 等价类、置换的不动点计数。 |
| 生成函数 | 普通/指数生成函数、卷积 | 系数意义、乘法对应组合构造。 |
| 计数 DP | 状压计数、树形计数、数位计数 | 状态是否避免重计，转移是否完备。 |
