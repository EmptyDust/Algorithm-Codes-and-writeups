# 0x80 String

这里作为字符串专题索引和历史题目入口。内容包括匹配、哈希、Manacher、Z 函数和 AC 自动机等。新题代码优先按来源放入 [`../-0x30_competition`](../-0x30_competition/)。

## 子目录

| 目录 | 内容 |
| --- | --- |
| [`0x81_match`](./0x81_match/) | 字符串匹配、KMP 等。 |
| [`0x82_hash`](./0x82_hash/) | 字符串哈希。 |
| [`0x83_manachar`](./0x83_manachar/) | Manacher 回文算法。 |
| [`0x84_misc`](./0x84_misc/) | 其他字符串题。 |
| [`0x85_z_function`](./0x85_z_function/) | Z 函数。 |
| [`0x86_ac`](./0x86_ac/) | AC 自动机。 |

## 使用约定

字符串题建议在索引或题解中保留边界样例，例如空串、重复字符、长公共前后缀等。若核心是 Trie 数据结构，也可在 [`../0x10_data_structure/0x19_trie`](../0x10_data_structure/0x19_trie/) 中交叉链接。
