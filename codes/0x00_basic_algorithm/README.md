## 知识点索引

| 方向 | 知识点 | 复习重点 |
| --- | --- | --- |
| 复杂度与实现 | 时间复杂度、空间复杂度、常数、边界数据 | 估算复杂度，避免溢出和越界。 |
| 前缀与差分 | 前缀和、二维前缀、差分、扫描贡献 | 区间统计、批量区间修改、贡献拆分。 |
| 排序与离散化 | 比较器、稳定性、离散化、排名映射 | 排序后维护相邻关系，坐标压缩。 |
| 二分 | 二分查找、二分答案、浮点二分 | 单调性证明，边界和开闭区间。 |
| 双指针 | 尺取、滑动窗口、同向/相向双指针 | 维护窗口不变量，控制指针移动次数。 |
| 贪心 | 交换论证、局部最优、排序贪心 | 证明局部选择不会破坏全局最优。 |
| 递归与分治 | 分治、递归边界、归并思想 | 子问题拆分、合并代价、递归深度。 |
| 搜索基础 | DFS、BFS、回溯、剪枝 | 状态设计、访问标记、剪枝正确性。 |
| 模拟 | 状态机、事件处理、细节实现 | 按题意维护状态，拆分复杂流程。 |
