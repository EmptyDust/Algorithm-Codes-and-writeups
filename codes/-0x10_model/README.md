# -0x10 Model

这里保存偏“模型化”的算法实现：同一类结构或技巧会放在固定子目录里，便于之后从题解中提取、复用或对照。它不是题目代码主归档，也不要求像模板一样稳定。

## 子目录

| 目录 | 内容 |
| --- | --- |
| [`-0x11_segment_tree`](./-0x11_segment_tree/) | 线段树相关模型与变体。 |
| [`-0x12_sort`](./-0x12_sort/) | 排序模型、排序相关技巧。 |
| [`-0x13_pbds`](./-0x13_pbds/) | GNU PBDS 相关用法。 |
| [`-0x14_binary_indexed_tree`](./-0x14_binary_indexed_tree/) | 树状数组模型。 |
| [`-0x15_string`](./-0x15_string/) | 字符串算法模型。 |
| [`-0x16_math`](./-0x16_math/) | 数学模型与常用推导实现。 |
| [`-0x17_recursion`](./-0x17_recursion/) | 递归与基础过程模型。 |

## 使用约定

这一层更偏“可迁移写法”，不是完整比赛归档。需要稳定模板时优先看 [`../-0x40_template`](../-0x40_template/)，需要按知识点复习时看正向 `0x*0` 分类目录，需要找题目代码时看 [`../-0x30_competition`](../-0x30_competition/)。
