# 0x60 Graphs And Trees

这里作为图论和树上问题的专题索引与历史题目入口。内容包括搜索、最短路、生成树、网络流、Tarjan、树上 DP 和图上的数据结构技巧。新题代码优先按来源放入 [`../-0x30_competition`](../-0x30_competition/)。

| 目录 | 内容 |
| --- | --- |
| [`0x61_search`](./0x61_search/) | DFS、BFS、搜索剪枝。 |
| [`0x62_twosat`](./0x62_twosat/) | 2-SAT 与布尔约束建图。 |
| [`0x63_mst`](./0x63_mst/) | 最小生成树及其变体。 |
| [`0x64_heuristics`](./0x64_heuristics/) | 启发式搜索或启发式合并。 |
| [`0x65_shortest_path`](./0x65_shortest_path/) | 最短路、差分约束和路径模型。 |
| [`0x66_net_flow`](./0x66_net_flow/) | 网络流、匹配与割。 |
| [`0x67_dsu`](./0x67_dsu/) | 图论语境下的并查集。 |
| [`0x68_haffman`](./0x68_haffman/) | Huffman 树与最优合并。 |
| [`0x69_simulate`](./0x69_simulate/) | 图或树上的模拟题。 |

## 使用约定

同一题若同时涉及图论和数据结构，可以在多个专题索引中链接同一份来源代码；模板化实现可同步整理到 [`../-0x40_template`](../-0x40_template/)。
