# 0x60 Graphs And Trees

图论与树上问题专题索引。题目代码按来源归档；这里整理从建图、遍历到高级图算法的复习顺序。

## 知识点索引

| 方向 | 知识点 | 复习重点 |
| --- | --- | --- |
| 图基础 | 建图、邻接表、边集、反图 | 有向/无向、重边、自环、边权。 |
| 遍历 | DFS、BFS、连通块、二分图染色 | 访问状态，递归深度，队列层次。 |
| DAG | 拓扑排序、DAG DP、传递关系 | 入度维护，环检测，拓扑序转移。 |
| 最短路 | Dijkstra、Bellman-Ford、SPFA、Floyd | 权值范围，负边，路径恢复。 |
| 生成树 | Kruskal、Prim、最小瓶颈树 | 边排序，并查集，唯一性。 |
| 连通性 | Tarjan、SCC、割点、割边、点双/边双 | `dfn/low` 语义，缩点建图。 |
| 2-SAT | 蕴含图、强连通分量、方案构造 | 变量与否命题建模。 |
| 树基础 | 直径、重心、LCA、树上差分 | 根的选择，倍增，路径拆分。 |
| 树链剖分 | HLD、链上数据结构 | 重链性质，线段树维护路径。 |
| 树上技巧 | DSU on tree、虚树、点分治 | 子树信息合并，关键点压缩。 |
| 网络流 | 最大流、最小割、费用流、二分图匹配 | 建模，容量含义，割的解释。 |
| 欧拉与匹配 | 欧拉路、一般匹配、稳定匹配 | 度数条件，连通条件。 |
